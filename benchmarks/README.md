# Reproducible smoke evaluation

For the unreleased speech-input milestone, run
`python benchmarks/evaluate_speech.py --check`. Its
[30 synthetic-fixture results](speech-results.md) measure exact output strings,
including intentional retention, separately from diacritization. Regenerate with
`python benchmarks/evaluate_speech.py --output benchmarks/speech-results.md`.
See [scope and limitations](../docs/speech-normalization.md).

```bash
python -m pip install -e ".[dev]"
python benchmarks/evaluate_diacritics.py
python benchmarks/evaluate_diacritics.py --output benchmarks/results.md
python benchmarks/evaluate_diacritics.py --check
```

The default command runs offline after dependencies are installed. The checked-in
[results](results.md) are generated by the script, not estimates. `--check` fails
if measured results no longer match that file. Run from the repository root.

## Data and license

The [data](data/) consists of 12 hand-authored, hand-checked diacritization pairs
and 24 numeric cases, covered by the repository's MIT license. No external
licensed corpus was available offline in the checkout. See the [provenance
note](data/README.md). These examples are a smoke test, not a representative
accuracy benchmark or evidence of model superiority. Numeric cases intentionally
cover the supported rules; passing all 24 does not imply correctness for every
Arabic number, grammatical context or dialect.

## Method

- Dictionary mode has four fixed entries listed in the script. They overlap the
  evaluation set. Unknown words retain their input spelling; low general-text
  coverage is expected for a small dictionary.
- **DER (Diacritization Error Rate):** incorrect mark sequences divided by Arabic
  base letters. All Arabic letters count, including unmarked letters and final
  case endings. Whitespace, punctuation, digits and English do not count.
- Base text must match exactly. Missing, inserted or changed base text raises an
  error rather than being excluded from the score.
- **WER (Word Error Rate):** word-level Levenshtein edit distance divided by the
  number of reference words. This includes insertions/deletions and can exceed
  100%. Words are split on whitespace. For an empty reference the denominator is 1.
- Unicode NFC normalization makes equivalent combining-mark orders compare equal.
- Corpus scores pool character/word errors and denominators across sentences,
  rather than averaging sentence percentages. Numbers use exact string equality.
- No timing results are reported. Environment/model download and warm-up times
  would make casual speed comparisons misleading.

## Optional neural evaluation

```bash
# Requires a platform supported by upstream onnxruntime-gpu (Linux/Windows).
python -m pip install -e ".[dev,catt]"
python benchmarks/evaluate_diacritics.py --catt
```

This explicitly enables both neural models and may download model weights. An
installation/model/alignment failure is an error, not a fabricated score.
The default [results](results.md) contain no CATT measurements. Separate
[post-release CPU results](catt-results.md) were generated with both real models;
[environment and reproduction](../docs/release-verification.md) record the manual
CPU installation. Current upstream GPU wheels do not support macOS. The package
wrapper preserves original text and transfers only vowel marks from predictions
with matching Arabic base letters.
