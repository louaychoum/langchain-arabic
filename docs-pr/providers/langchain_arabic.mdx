# langchain-arabic

This file is a local integration-page draft. It is not evidence of a published
LangChain integration page.

`langchain-arabic` provides `ArabicTextOutputParser`, a `langchain-core` output
parser for caller-supplied diacritics mappings and number-to-word conversion.
Dictionary processing runs locally without model downloads.

## Setup and usage

```bash
pip install langchain-arabic
```

```python
from langchain_core.language_models.fake_chat_models import FakeListChatModel
from langchain_arabic import ArabicTextOutputParser

llm = FakeListChatModel(responses=["شركة تقنية حققت نسبة 95% نمو"])
parser = ArabicTextOutputParser(
    diacritics_map={"شركة": "شَرِكَة", "تقنية": "تِقْنِيَّة"},
)
chain = llm | parser
result = chain.invoke("كيف كان النمو؟")
# شَرِكَة تِقْنِيَّة حققت نسبة خمسة و تسعون بالمائة نمو
```

The fake chat model requires no API key. Real providers require their own package
and credentials. Only mapped words receive diacritics in dictionary mode.

## Configuration

| Parameter | Default | Meaning |
|---|---|---|
| `backend` | `"dictionary"` | Dictionary replacement or optional `"catt"` |
| `catt_model` | `"encoder_only"` | Also accepts `"encoder_decoder"`; no accuracy guarantee |
| `dialect` | `"msa"` | Also accepts `"gulf"`: four substitutions and supplied dialect maps |
| `diacritics_map` | `{}` | Flat/dialect-keyed dict, existing UTF-8 file path, or mapping text |
| `convert_numbers` | `True` | Convert supported numeric tokens |
| `language` | `"ar"` | Arabic or `"en"` number words |
| `number_contexts` | `None` | All contexts; use a set to select or disable them |

Number contexts: `percentage`, `currency_ar`, `currency_en`, `phone`, `plain`.
Western/Eastern Arabic digits and signed decimals are supported. Fractional digits
are spoken individually. No noun agreement, ordinal inference or full dialect
morphology is provided. Phone-style reading needs an explicit cue/leading `+`,
or phone-only context for a bare long number.

## Async and streaming

`ainvoke` and `abatch` are supported. Both synchronous and asynchronous streams
buffer the full answer, then yield one processed string. They do not emit processed
tokens incrementally. Text message blocks are extracted without exposing reasoning
or image blocks as stringified dictionaries.

## Optional CATT

`pip install "langchain-arabic[catt]"` uses upstream `catt-tashkeel` and ONNX GPU
runtime dependencies on supported Linux/Windows platforms. The extra currently
cannot resolve on macOS. Models load on first use and may download weights.
Numbers are converted first, followed by neural diacritization and dictionary
overrides. The wrapper preserves original content and rejects changed base letters.
Neural inference and accuracy were not validated for the 0.3.1 preparation.
