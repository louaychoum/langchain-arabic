# langchain-arabic

LLMs produce Arabic text without diacritics (tashkeel) 60–70% of the time. This causes mispronunciation in text-to-speech (TTS) pipelines and reduces readability. Numbers in digit form are also read incorrectly by TTS engines.

`langchain-arabic` is a LangChain output parser that post-processes LLM output with:

- **Diacritics restoration** — deterministic dictionary replacement or neural auto-diacritization via [catt-tashkeel](https://pypi.org/project/catt-tashkeel/)
- **Number-to-word conversion** — context-aware (percentage, currency, phone, plain)
- **Dialect support** — dialect-specific diacritics maps and number phrasing (MSA, Gulf)

## Setup

### Installation

<CodeGroup>
```bash pip
pip install -U langchain-arabic
```
```bash pip (with neural backend)
pip install -U "langchain-arabic[catt]"
```
</CodeGroup>

## Components

| Component | Package | Description |
|-----------|---------|-------------|
| `ArabicTextOutputParser` | `langchain-arabic` | Output parser combining diacritics restoration, number-to-word conversion, and dialect-aware phrasing |

## Usage

### Dictionary-based diacritics

Provide a mapping of plain Arabic words to their diacritized forms. The parser applies longest-first replacement to prevent partial matches.

```python
from langchain_arabic import ArabicTextOutputParser

parser = ArabicTextOutputParser(
    diacritics_map={
        "تقنية": "تِقْنِيَة",
        "شركة": "شَرِكَة",
        "علم الحاسوب": "عِلْمُ الحَاسُوبِ",
    },
    convert_numbers=False,
)

result = parser.parse("شركة تقنية في علم الحاسوب")
# "شَرِكَة تِقْنِيَة في عِلْمُ الحَاسُوبِ"
```

### Number-to-word conversion

Numbers are detected and converted based on context:

```python
parser = ArabicTextOutputParser(convert_numbers=True, language="ar")

parser.parse("النسبة 95%")
# "النسبة خمسة و تسعون بالمائة"

parser.parse("المبلغ 500 ريال")
# "المبلغ خمسمائة ريال"

parser.parse("اتصل على 920001234")
# "اتصل على تسعة اثنان صفر صفر صفر واحد اثنان ثلاثة أربعة"
```

### Chain integration

`ArabicTextOutputParser` slots into any LCEL chain as a drop-in replacement for `StrOutputParser`:

```python
from langchain_arabic import ArabicTextOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

prompt = ChatPromptTemplate.from_template(
    "اشرح {topic} باللغة العربية في جملتين."
)
llm = ChatOpenAI(model="gpt-4o-mini")
parser = ArabicTextOutputParser(
    diacritics_map={"تقنية": "تِقْنِيَة"},
    convert_numbers=True,
)

chain = prompt | llm | parser
result = chain.invoke({"topic": "الذكاء الاصطناعي"})
```

<Note>
The parser buffers all streaming chunks and processes the complete text once the LLM finishes, because diacritics and number conversion require complete words.
</Note>

### Dialect support

Use the `dialect` parameter for dialect-specific number phrasing and dialect-keyed diacritics maps:

```python
# Gulf dialect — numbers use Gulf phrasing
parser = ArabicTextOutputParser(dialect="gulf", convert_numbers=True)
parser.parse("النسبة 100%")
# "النسبة مية بالمية" (not "مائة بالمائة")

# Dialect-keyed diacritics maps
parser = ArabicTextOutputParser(
    dialect="gulf",
    diacritics_map={
        "msa": {"تقنية": "تِقْنِيَة"},
        "gulf": {"تقنية": "تَقْنِيَّة"},
    },
    convert_numbers=False,
)
```

Supported dialects: `"msa"` (Modern Standard Arabic, default), `"gulf"` (Khaleeji).

### CATT neural backend

For full auto-diacritization without a manual dictionary (requires `pip install langchain-arabic[catt]`):

```python
parser = ArabicTextOutputParser(
    backend="catt",
    catt_model="encoder_only",  # or "encoder_decoder" for higher accuracy
)

result = parser.parse("نص عربي بدون تشكيل")
```

Hybrid mode applies dictionary overrides after neural diacritization — useful for proper nouns and brand names:

```python
parser = ArabicTextOutputParser(
    backend="catt",
    diacritics_map={"شركتنا": "شَرِكَتُنَا"},
)
```

## Configuration reference

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `backend` | `str` | `"dictionary"` | `"dictionary"` or `"catt"` |
| `catt_model` | `str` | `"encoder_only"` | `"encoder_only"` or `"encoder_decoder"` |
| `dialect` | `str` | `"msa"` | `"msa"` or `"gulf"` |
| `diacritics_map` | `dict \| str` | `{}` | Word mappings (dict, file path, or text) |
| `convert_numbers` | `bool` | `True` | Convert digits to words |
| `language` | `str` | `"ar"` | `"ar"` or `"en"` |
| `number_contexts` | `set \| None` | `None` | Contexts to convert (`None` = all) |
