# Code of conduct

This project welcomes contributors with different backgrounds and levels of
experience. These rules apply to issues, pull requests, reviews and other project
spaces.

- Discuss code and evidence. Explain disagreement without personal attacks.
- Respect names, identities, privacy and different language abilities.
- Give specific, constructive feedback and accept corrections.
- Do not harass, threaten, discriminate, spam or publish another person's private
  information. Sexual harassment and unwelcome sexual content are prohibited.

Maintainers may edit or remove harmful content, close discussions, or temporarily
or permanently restrict participation. They will consider context, severity and
repeated behavior and explain decisions where doing so respects privacy.

Report concerns to the maintainer through the contact options on
[their GitHub profile](https://github.com/louaychoum). If a private contact option
is unavailable, request a private reporting channel without posting sensitive
information in public. Reports should include links and a factual description.
Maintainers will handle personal information discreetly and avoid retaliation
against people who report concerns in good faith.
